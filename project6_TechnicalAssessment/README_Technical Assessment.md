# Technical Assesemnt - Financial Risk Profiling

# Overview
This project investigates the relationships between public records and loan performance. The focus of this project is to showcase technical skills during assessment.   

# Objectives
1. Identify relationships between data  
2. Showcase data processing techniques  
3. Demonstrate statistical proficiency during analysis  

# Methods
**Datasets:** There are 3 datasets used in this project: public records data, loan performance data, and a data dictionary.   
**Data Preparation:** Datasets were cleaned and formatted for analysis.  
**Modeling:** Evaluated various models (e.g., Linear Regression, Random Forest).  
**Risk Assessment:** Investigated the application of a risk assessment profile to predict probability of default.   

# Key Findings
**Anomalies:** Anomalies identified in the data can help with curating a risk profile of either high-impact or high-risk clients. 
**Relationship:** The data showed limited relationships between features. Additional data and context would need to be incorporated to draw meaningful conclusions or build accurate models. 
**Risk Assessment:** Given additional data, a profile could be created to identify risky clients for the purpose of intervention or assessment for initial approval. 

# Discussion
Analyzing time series data can shed light on economic and financial trends, lending tools to mitigate risk during periods of recession or economic hardship. These trends can also help identify yearly cyclical relationships between loan performance, providing a framework for operational interventions that could improve revenue and 
customer satisfaction.   
  
When examining data to look for relationships and possible predictive power, it is important to understand the limitations of the dataset and the context in which models could be applied. Although the dataset given did not show a strong relationship between variables, a scaffold for a simulation model can be built that could account for more complexity were additional variables to be added into analysis.  

# Limitations
Limited relational correlations between features of this dataset lead to less accurate modelling.
